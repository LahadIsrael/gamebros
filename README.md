# GameBros

## Overview

GameBros is a community based platform for gamers of all types. It was created for those that sought a relatable community that they could join and have fun with. There are numerous social media platforms out there such as Facebook, Instagram, Tiktok, however none dedicated to gamers. This is different because it operates as a centralized location for gamers to connect and socialize bringing a community of different races, backgrounds, and cultures together.
