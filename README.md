# GameBros

## Overview

GameBros is a community based platform for gamers of all types. It was created for those that sought a relatable community that they could join and have fun with. There are numerous social media platforms out there such as Facebook, Instagram, Tiktok, however none dedicated to gamers. This is different because it operates as a centralized location for gamers to connect and socialize bringing a community of different races, backgrounds, and cultures together.

## Features

### Functional

#### Landing Page

- Hero section with site name/tagline
- Brief description of what the site is
- Call to action (ex: "Join the Community")
- Preview of features (friend system, tournaments, gamertag sharing)

#### Gamer Profile Page

- Display name / username
- Avatar/profile photo
- Bio section
- Platform tags listed (PSN, Xbox Gamertag, Steam, etc.)
- Games they play
- Friend list display
- Tournaments entered or hosted

#### Friend System

- Send/accept friend requests
- View friends list
- Search for other gamers

#### Tournament Section

- Create a local tournament
- Browse open tournaments
- Join a tournament

#### Community Features (Facebook-like)

- Activity feed / posts
- Comments
- Like/react to posts

### Non-Functional

- Works on desktop and mobile (responsive)
- Fast load times
- Clean, gaming-themed design (dark mode aesthetic fits the audience)
- Easy navigation
